# Hallow Receipt Registry

This optional registry anchors public commitments for a job intent, Agent Passport, policy, deliverable, and evidence root. It is deliberately non-custodial: no tokens, wallet keys, prompts, raw deliverables, or private memory are accepted or stored.

The TypeScript Arc integration works without this contract. Any future Arc deployment must begin on Public Testnet, publish verified source, and complete an independent audit before production use. No production address is published until those steps are complete.
