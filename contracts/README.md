# Hallow Receipt Registry

This optional Robinhood Chain contract anchors only four public hashes: the guarded plan, Asset Passport, policy, and approval. It is deliberately non-custodial: no tokens, wallet keys, prompts, or private memory are accepted or stored.

The TypeScript Guardian works without this contract. Deploy the registry to Robinhood Chain testnet first, verify the source, and commission an independent audit before considering mainnet use. No production address is published until those steps are complete.
